AI Chat — RAG Flow
City-level questions grounded in real case data · zero extra infra · fully client-side retrieval
1
Build-time Embeddings
Node.js script runs once — embeds all 298 cases with all-MiniLM-L6-v2 → saves 298 × 384-dim vectors to embeddings.json. Re-run when case data changes.
2
In-browser Retrieval
User query → @huggingface/transformers WASM (same model, runs client-side, ~25 MB one-time download) → cosine similarity vs all 298 vectors → top-5 case IDs.
3
Grounded LLM Response
Top-5 CaseFull records injected into system prompt → Qwen 27B via Groq answers with real ward names, real scores, real complaint counts. No hallucination.
